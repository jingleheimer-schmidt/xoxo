## xoxo
a mod for factorio
https://mods.factorio.com/mod/xoxo

---------------------
# Overview
hugs and kisses! press xoxo to tell your friends you love them

---------------------
# Features
- press x and o to send out hugs and kisses <3
- 113 hand-drawn sprites

---------------------
## Companion Mods
xoxo is a companion mod to:
[Rainbow Character](https://mods.factorio.com/mod/rainbow-character)

---------------------
# Compatibility
To report a compatibility issue, please make a post on the discussion page.
Since the default key binding for toggling train overview is `O`, consider changing it to avoid toggling the gui unintentionally when pressing `O` for xoxo.
